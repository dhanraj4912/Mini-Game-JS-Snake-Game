# 🐍 WebSnake - Classic Snake Game in the Browser

A browser-based Snake game built using **HTML**, **CSS**, and **JavaScript Canvas API**. Guide the snake to eat food, grow longer, and avoid crashing into the walls or itself.

## 🚀 Features

- Keyboard-controlled snake movement (Arrow keys)
- Food generation with score tracking
- Collision detection (self and wall)

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Canvas API)

## ▶️ How to Play

1. Clone the repository or download the files.
2. Open `index.html` in any modern browser.
3. Use **arrow keys** to move the snake.
